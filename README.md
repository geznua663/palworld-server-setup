# 幻兽帕鲁服务器搭建：一键开服加改倍率，从4人小队到20人公会的配置和花费怎么选

玩《幻兽帕鲁》联机，大多数人的第一课是"房主不能关电脑"。四个人凑一桌还能忍，一旦想拉上七八个朋友，或者房主那台机器的配置、网络本来就不太行，掉线、卡顿、存档跟着一台台机器走的问题就全冒出来了。专用服务器解决的就是这件事：服务端自己跑着，谁下线都不影响世界，经验倍率、捕获率、白天长度这些也能按你们的玩法改。

下面按实际的决策顺序来：先确认要几个人玩、需要什么配置，再决定用哪种方式开服，最后是价格、开服步骤和长期运行才会遇到的坑。

## 开服前先定三件事：人数、内存、端口

### 内存比 CPU 更值得优先堆

游戏官方给出的专用服务器推荐配置是 4 核 16G，最低 8G。这是推荐值，不是门槛——两三个人在一个小据点里折腾，4 核 8G 也能跑起来。但帕鲁服务端的内存占用会随着在线人数、据点建造规模、世界存档大小持续往上走，开得越久涨得越明显，长期不重启可能出现内存溢出导致崩服。

按人数的配置参考大致是这样：

| 联机人数 | 建议配置 | 带宽 | 说明 |
| --- | --- | --- | --- |
| 2–4 人 | 2 核 8G 起 | 10M | 据点规模不大时够用，配合定期重启很稳 |
| 4–8 人 | 4 核 16G | 15M | 对应官方推荐档位 |
| 8 人以上 | 4 核 16G 至 8 核 32G | 20M 以上 | 人数和据点一多，内存需求上升很明显 |

预算有限的时候先把内存选够，CPU 核数够用就行。帕鲁服务端的卡顿多数来自内存不足，不是算力不够。

### 端口只需要记一个

**UDP 8211**。游戏联机走这个端口，而且必须是 UDP 协议。填成 TCP 的典型症状是：服务端日志看着一切正常，客户端就是连不上，也不给任何明显报错，排查起来很浪费时间。

## 三种开服方式，按你愿意折腾的程度选

### 方式一：面板服一键开服，完全不碰命令行

改配置也有可视化界面：世界设置文件在 `/pal/Pal/Saved/Config/LinuxServer/PalWorldSettings.ini`，面板里能直接编辑，保存后重启实例生效。

限制也说清楚：面板服跑在 Docker 容器里，一般只能跑一个实例，适合单端单服。想在同一台机器上开好几个服端，那就得看 VPS。

### 方式二：VPS 加预装帕鲁，要系统权限但不想装环境

买游戏云 VPS 的时候勾上"帕鲁预装"；已经买好了也可以在"重装系统或软件"里勾选安装。系统选 Windows Server，等安装完成的提示出来，用远程桌面连上去，双击桌面上的启动脚本，玩家用 `你的IP:8211` 进服。默认配置文件在 `C:\PalServer\Pal\Saved\Config\WindowsServer\PalWorldSettings.ini`，服务器名、密码、人数都在里面改。

VPS 的默认机型是 NAT 网络，跟别人共用一个公网 IP，可以开 15 条端口映射，做游戏私服完全够；需要独占的话，部分机房支持加购独立公网 IP。

### 方式三：Linux 加 SteamCMD，手动部署

适合想把每一步都攥在自己手里的人。先装 32 位兼容库，缺了它启动时会报找不到共享库：

bash
sudo dpkg --add-architecture i386
sudo apt install -y lib32gcc-s1 steamcmd


然后用 SteamCMD 拉服务端，`2394010` 是帕鲁专用服务端的 Steam App ID：

bash
steamcmd +login anonymous +app_update 2394010 validate +quit


`validate` 会校验文件完整性，首次下载体积不小，慢是正常的。下载完在 `PalServer` 目录里启动服务端，再按下面的端口步骤放通 8211/UDP。

## 开服后最容易卡住的三个点

**端口协议选错。** 8211 必须是 UDP。VPS 的 NAT 端口映射、云服务器的安全组、系统防火墙三处都可能拦住它，Windows 系统的防火墙在雨云镜像里默认是关的，自己动过的话记得检查。

**面板地址拿错。** 面板服的对外地址是"域名加端口"的组合，不是常见的那种纯 IP。另外如果买的是宿迁地区的 MCSM 面板，PalWorld 面板里要选 UDP 专用地址，普通地址连不上。

**世界配置是空的。** 面板服里的 `PalWorldSettings.ini` 初始内容为空，需要把同目录上一级的 `DefaultPalWorldSettings.ini`（默认模板）里的内容整个复制进去，再改里面的参数，改完重启实例生效。模板文件本身不要动。

## 世界参数：三个最常改的，一个别乱动

改配置文件时记住一个规则：数值都是倍数，保留六位小数，`1.000000` 调一半就是 `0.500000`。

- `ExpRate`：经验倍率。想快点追进度就调，上限 20 倍。
- `DayTimeSpeedRate` / `NightTimeSpeedRate`：昼夜流逝速度。数字越小，白天或夜晚越长，懒得摸黑干活就把夜晚调慢。
- `PalCaptureRate`：捕获概率倍率，手气不好可以适当加。
- `ServerPassword`：服务器密码。不想被陌生人摸进来就设上，改完记得告诉队友。
- **`PalSpawnNumRate` 别乱动。** 帕鲁出现数量倍率超过 1 之后，服务器性能会明显下降，人多的服直接卡成幻灯片。

## 长期开服要留意的事

内存是会涨的。跑得越久、据点越大，占用越高，隔几天手动或定时重启一次能避免半夜崩服。雨云帮助文档里还提供过一个非官方修复内存泄漏和高 CPU 负载的服务端版本，遇到反常的内存曲线可以去翻一下。

存档操作前**一定先关服务端**，不然有损坏风险。换机器、重装、升级配置之前记得导出存档。

服务端更新同样走 SteamCMD 那条命令，`validate` 会自动补上缺失文件。想装 MOD 的话注意：目前模组安装只支持 Windows 系统，Linux 服端还不支持。

对配置项英文发懵的，雨云百科里有配置说明的中英文对照表，比逐个猜字段省事。

## 常见问题

**只想和朋友三个人玩，用不用上 16G？**
4 核 8G 可以先试，花 1 元试用一天跑跑看。据点铺得大、帕鲁存得多，再升 16G 也来得及，雨云支持随时升降配。

**需要买独立公网 IP 吗？**
NAT 机型可以开 15 条端口映射，开一个帕鲁服只需要一条，够用。队友连的时候用的也是那个映射出来的地址端口。除非你打算在这台机器上跑一堆对外服务，否则没必要多花钱。

**队友连不上但服务器显示正常，先查什么？**
先确认端口填的是 UDP 8211 并且真的放通了，再确认地址里带上端口号。这两条占八成原因。

**一年下来大概多少钱？**
按 4 核 8G 面板服算，官方论坛公开过的原价档位从 E5 机型的约 70 元/月到高主频机型的约 180 元/月，年付 7 折之后差距会等比缩小。一群朋友平摊下来，一个月一杯奶茶的级别。

选配置这件事没有标准答案，判断标准就一条：你们几个人、每天玩多久、据点多不多。人数少又想省钱，入门机型加动态计费就够了；人多、天天开、还想装点东西进去，把钱花在内存和高主频上，比事后崩服再折腾要便宜。
